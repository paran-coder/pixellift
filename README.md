# PixelLift v1.1.0

무료 브라우저 기반 AI 이미지 업스케일러. v1.0.4에서 이어지는 새 품질 프리셋 버전입니다.

## 이번 버전의 목적
이미지 유형을 직접 선택하는 복잡함을 없애고, 화면 가로 3열의 원본 보존·균형·선명도 강화 옵션을 제공합니다. 기본은 원본 보존입니다.

## 개발
`npm test` · `npm run build` · `npm run dev`

## 실행 환경
정적 웹 앱. ONNX Runtime Web, Real-ESRGAN ONNX, WebGPU 또는 WASM 대체를 사용합니다. 실제 CDN 모델 다운로드와 실기기 성능은 별도 검증합니다. 이미지 원본은 로컬 브라우저에서 처리됩니다.

## 사용한 처리 정책
- **원본 보존:** 원본 4배 보간 베이스를 보존하고 AI 고주파 디테일만 제한적으로 반영 (모델 자체는 실행)
- **균형:** 원본 베이스와 AI 예측의 중간 혼합 및 선명도 보강
- **선명도 강화:** AI 예측을 더 강하게 반영하므로 질감/선 모양 변형 가능
- 2×는 4배 모델 출력을 리샘플링한 결과입니다. 출력 이미지 용량·메모리는 원본 크기에 따라 달라집니다.

## 모델 라이선스
Real-ESRGAN 및 ONNX 변환 모델의 사용 조건은 공개 전에 재검토해야 합니다. 원본 파일과 다운로드한 모델은 서버가 아닌 사용자의 브라우저에서 처리하도록 구성했습니다.

## 검증 현황
테스트 성공은 실제 품질이 합격했다는 의미가 아닙니다. QA_REPORT.md 참고.
