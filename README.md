# PixelLift v1.2.1

기본 전체 이미지를 표시하고, 업스케일 완료 후 `확대 비교`를 눌러 원본·결과를 같은 위치로 4배 확대·드래그 이동할 수 있습니다. 비교 슬라이더도 사용할 수 있습니다.

# 이전 버전: PixelLift v1.2.0

원본 보존을 우선하는 브라우저 기반 무료 AI 이미지 업스케일러. 이미지 종류 구분 없이 **원본 보존·균형·선명도 강화** 3개 품질을 가로로 배치하며, 이미지 전체 폭 미리보기·클릭 업로드·드래그앤드롭·2×/4× PNG 저장을 지원합니다.

## 개발 및 테스트

Node.js 20 이상 필요. 정적 사이트이며 외부 ONNX Runtime Web / Real-ESRGAN 모델을 다운로드할 네트워크와 지원 브라우저가 필요합니다.

```bash
npm test
npm run build
npm run dev
node scripts/benchmark-quality.mjs
```

`dist/`를 정적 호스팅에 업로드하거나 GitHub와 Vercel Git 배포를 연결할 수 있습니다. 로컬의 `index.html`도 `src/client.js`와 함께 열 수 있습니다.

## 품질 로직

- 원본 보존: 원본을 보간한 **기본 이미지의 큰 구조와 색**을 기준으로 AI의 두 주파수대 디테일을 원본 경계 근처에만 제한적으로 반영. 강한 AI 변경을 제한함.
- 균형: 원본 기반 처리에 AI 예측을 적당히 혼합.
- 선명도 강화: AI 예측을 더 강하게 반영하므로 색·질감 변형 가능.
- 보존형에서 AI가 실질적으로 기여하지 못하면 기존 원본의 경계만 보수적으로 선명화하며, 적용된 타일 수를 결과 정보에 표시. **대체 처리는 AI 정보 복원과 같지 않음.**

## 처리 한계

기계적 수치 개선과 인간이 느끼는 시각 품질은 다릅니다. 원본의 진짜 세부 정보를 복원했다는 보장은 없습니다. 화질 판단에는 동등한 확대 배율의 일반 Bicubic/Lanczos 대조와 실모델 비교가 필수입니다. 실제 모델의 출력 품질은 이미지별로 검증해야 하며, 확대 UI 추가만으로 화질이 개선되지는 않습니다.

## v1.2.1 확대 비교 기능

- 업스케일 완료 전에는 확대 버튼이 나타나지 않습니다.
- 완료 후 `확대 비교 · 4×`를 누르면 같은 위치의 Before/After를 동기 확대합니다. 드래그로 위치를 이동하며 중앙 손잡이로 비율을 조절할 수 있습니다. `전체 보기`를 누르면 1배 전체 화면으로 복원됩니다.
- 확대 상태에서는 중앙 손잡이를 포인터로 끌어 비교하고, 비교 슬라이더에 키보드 포커스를 두면 좌·우 화살표로도 조절할 수 있습니다.
- 결과 삭제·다른 이미지 업로드·설정 변경 시 확대 상태는 자동 초기화됩니다.
- 확대 비교는 오직 표시 UI이며 실제 업스케일 엔진의 품질을 높이지 않습니다.

## 품질 출시 기준(목표; 현재 통과 판정 아님)

30장 이상의 대표 이미지를 확보해 인물/풍경/제품/일러스트/애니메이션 등을 포함하고, 동일 확대율 Bicubic을 대조군으로 사용합니다. 100% 및 200% 동일 영역에서 독립적인 육안 비교를 시행하며, **80% 이상 샘플에서 더 좋은 유효 디테일**을 보여야 합니다. 얼굴·손·텍스트·선화 구조의 중대한 변형은 **0건**, 명백한 질감 훼손 역시 없어야 합니다. 2×/4× 크기를 정확히 저장하고 대상 브라우저에서 실제 완료·저장 성공률이 최소 **95%**여야 합니다. 80%/95%는 사전 합격 목표이며 측정 완료 수치는 아닙니다.

SSIM/PSNR이 우수해도 선명도 향상을 입증하지 않으며, 자동 평균 픽셀 차이는 화질이 아닙니다. 기존 자동 `source-sharpen` 대체는 실제 디테일의 생성이 아니며, AI 모델 효과가 없어도 무조건 품질 향상을 주장하지 않습니다.
