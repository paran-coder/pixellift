# PixelLift v1.3.0

브라우저에서 무료로 실행하는 2×/4× Real-ESRGAN 기반 이미지 업스케일러입니다. **원본의 형태·색상·화풍을 훼손하지 않는 범위에서 체감 가능한 선명도 향상**을 목표로 합니다. 실제 고해상도 정답의 100% 복원을 보장하지 않습니다.

## 시작하기

```bash
npm test
npm run build
npm run dev
```

정적 호스팅 시 `dist` 폴더를 Vercel에 배포합니다. `npm run build`는 `src/engine.mjs`와 `src/main.mjs`를 하나의 고전적인 `src/client.js`로 묶습니다. **생성된 client.js는 직접 수정하지 마세요.**

## UI

전체 너비 이미지 업로드(클릭/드래그앤드롭), 가로 3열 품질 메뉴(원본 보존/균형/선명도 강화), 2×/4×, Before/After, 4× 확대 비교/드래그 이동, PNG 다운로드. 파일 처리는 브라우저 내부에서 수행합니다.

## 품질 로직

v1.3.0부터 원본 확대의 기존 고주파를 다시 더하지 않고 `AI 결과 − 보간 결과`의 다중 주파수 **잔차**를 활용합니다. 평탄 배경의 환각을 제한하고, 모델이 소스의 경계를 거의 없애면 기준 확대 이미지를 그대로 사용합니다. 품질 이득이 미미한 경우 UI에 이를 표시합니다. 실제 AI 개선 효과는 모델/이미지에 따라 다릅니다.

## 검증 자료

- `QA_REPORT.md`: 실제 수행한 테스트, 한계, 자체 평가
- `MODEL_EVALUATION.md`: 다른 초해상도 모델의 문헌상 특징과 검증 필요 사항
- `quality-benchmark.json`: **합성 이미지** 벤치마크; 실제 화질 점수 아님
- `tests/fidelity-regression.test.mjs`: 독립 합성 정답/환각 억제/선택 프리셋 테스트

### 라이선스

프로젝트 코드 MIT. Real-ESRGAN 원본 및 배포 모델의 라이선스와 제3자 저작권 표기는 별도로 적용됩니다. 원격 모델은 SHA-256을 고정해 검증합니다. 제3자 모델과 가중치 라이선스는 모델 페이지에서 확인하세요.
